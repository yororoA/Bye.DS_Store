Quietly automatic

你打开文件夹，
它处理剩下的事。

没有常驻 Dock 图标，没有复杂的工作流。Bye.DS_Store 在菜单栏里， 只在需要时出现，像一个安静但可靠的桌面工具。

01

跟随 Finder

实时读取当前打开的文件夹，多个窗口自动去重，不打扰你的工作节奏。

02

延续一段时间

文件夹关闭后仍会保留在清理范围内，给 Finder 写入元数据留出时间。

03

适合你的规则

扫描范围、排除目录、轮询间隔都可以在设置中按你的习惯调整。

How it works

从活跃到近期活跃，清理有自己的节奏。

`.DS_Store` 经常在你进入子文件夹时生成到原目录。 默认策略因此会关注当前文件夹和它的直接父文件夹。

查看完整说明 ↗
打开一个 Finder 文件夹

应用每 5 秒读取一次 Finder 当前窗口目标，记录活跃目录。

进入它的子文件夹

清理当前目录和直接父目录，覆盖 macOS 常见的元数据写入位置。

关闭窗口也不急着忘记

目录会在默认 60 秒的宽限期内继续参与清理，然后自然退出。

Small, deliberate, transparent

不扫描你没选择的地方。

Bye.DS_Store 把清理边界写清楚，也把控制权留在你的手里。

✓默认只关注 Finder

后台自动清理只处理通过 Finder 监听到的相关目录，全盘扫描必须手动确认。

✓排除规则是标签

输入 node_modules 或 lib/packages，回车添加；点击叉号即可移除，规则本地保存。

✓跳过符号链接

扫描不会沿着符号链接进入另一棵目录树，减少重复扫描和意外越界。

✓完整结果可见

扫描后展示发现、删除、失败数量，并提供失败路径和错误信息供复核。
