Bye.DS_Store — нативное приложение для строки меню macOS. Оно отслеживает папки, открытые в Finder, периодически удаляет `.DS_Store` из связанных каталогов и ещё некоторое время сохраняет недавно закрытые папки в области очистки.

## Основные возможности

| Возможность | Что делает |
| --- | --- |
| Мониторинг Finder | Читает текущие окна Finder и автоматически убирает дубликаты |
| Отложенная очистка | После закрытия папка остаётся в области очистки 60 секунд по умолчанию |
| Область очистки | Текущая папка и её непосредственная родительская папка; можно выбрать только текущую |
| Полное сканирование | Ручное сканирование загрузочного, внешних, сетевых или всех подключённых дисков |
| Исключения | Исключает папки по имени или пути, например `node_modules` или `lib/packages` |
| Защитные границы | Подтверждение перед запуском, остановка во время работы и список ошибок после |
| Строка меню | Без значка в Dock, глобальное сочетание `⌘⌥B` |
| Языки | Автоопределение системы или 简体中文, 繁體中文, English, 日本語, Deutsch и Русский |

## Зачем очищать родительскую папку?

Практические тесты macOS показали, что при входе во вложенную папку `.DS_Store` часто записывается в исходную папку, а не непосредственно в корень открытой папки. Поэтому стандартная область включает:

1. Папку, которую сейчас отслеживает Finder
2. Её непосредственную родительскую папку

Приложение не поднимается выше по дереву и не сканирует вложенные папки автоматически.

## Полное сканирование и безопасность

Полное сканирование запускается вручную и не является частью фонового опроса.

- символические ссылки пропускаются, чтобы не заходить в другое дерево каталогов повторно;
- настроенные исключения и их содержимое пропускаются;
- подсчитываются просканированные, найденные, удалённые и ошибочные элементы;
- недоступные системные места записываются в отчёт, но не останавливают весь процесс.

Для некоторых системных каталогов нужен **полный доступ к диску** в настройках «Конфиденциальность и безопасность» macOS.

## Исключения

В настройках введите имя папки или путь «родительская/целевая» и нажмите Return:

```text
node_modules
lib/packages
```

Каждое правило становится удаляемым тегом. В начальный список входят распространённые каталоги зависимостей и сборки:

```text
node_modules, .venv, venv, __pycache__, vendor, Pods, target, .gradle
```

## Требования

- macOS 14 или новее
- Xcode 16 или новее
- Swift 6

## Локальный запуск

```bash
./scripts/run-app.sh
```

Только сборка:

```bash
./scripts/build-app.sh
```

Тесты:

```bash
swift test --disable-index-store
```

Собранное приложение находится в `dist/Bye.DS_Store.app`.

## Разрешения при первом запуске

При первом запуске macOS спросит, можно ли Bye.DS_Store управлять Finder. Разрешение используется только для чтения текущих расположений окон Finder.

Если доступ был запрещён:

```text
Системные настройки > Конфиденциальность и безопасность > Автоматизация > Bye.DS_Store > Finder
```

Для удаления файлов в защищённых местах, например на Рабочем столе, в Документах или Загрузках, может потребоваться отдельное разрешение.

## Release и GitHub Actions

Отправьте тег версии, чтобы запустить автоматическую публикацию:

```bash
git tag vX.Y.Z
git push origin vX.Y.Z
```

Workflow запускает тесты, собирает приложение macOS, создаёт zip/DMG и SHA-256, а при наличии Apple Developer secrets выполняет подпись Developer ID и notarization.

Описание Release хранится в:

```text
.github/release-notes/<tag>.md
```

Страница продукта публикуется через GitHub Pages по адресу [bye-dsstore.yororoice.top](https://bye-dsstore.yororoice.top/). Pages workflow получает последний Release при деплое и автоматически обновляет версию и URL DMG.
